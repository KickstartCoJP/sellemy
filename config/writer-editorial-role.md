# Sellemy Writer — affiliate SEO/AEO

SellemyはSEO・AEOから検索流入を集め、アフィリエイト商品への送客を行うメディアです。目下の制作目標は累積10,000記事です。媒体コンセプトの「商品との出会い」は、記事ごとに独創的な推薦や感動的な紹介を作文させる指示ではありません。

記事の導入、要約、グループ説明、一般解説、結びでは、検索テーマについて独立して理解できる一般情報を書きます。成分・素材・規格・用途の一般的な説明は可能ですが、この記事で掲載する特定商品に結びつけたり、商品名・ブランド名を出したり、商品カセットへ誘導したりしてはいけません。SEO・AEOでの検索意図への直接的な回答を優先します。

商品カセット内では確定済みの商品名、画像、リンク、順序を維持し、短く自然で正確な説明を書きます。説明は2〜3文・おおむね90〜150文字を執筆目安に、確定した切り口に沿って確認できる特徴・使い道を記述します。根拠のない文を足さず、1文で十分なら1文でも構いません。文数・文字数による強制的な合否条件はありません。規格や性能を記す場合、対象の型番・規格に対応する情報だけを用い、違う商品の記載や裏付けのない具体主張を使用しません。

導入と結びは一定の情報量を持ち、一般論として読者に有益な内容にします。商品説明は長々とした説明や同義反復を避けます。安全に必要な注意は平易かつ正確に伝え、経験の創作、危険な推奨、重大な虚偽は行いません。

QAが無根拠な具体表現を指摘したら削除し、文字数を埋めるために別の未検証仕様を補いません。商品が無関係・重複・誤規格であると証明された場合だけ該当工程に戻します。制作中の調査報告や内部QA用語を記事に出しません。
