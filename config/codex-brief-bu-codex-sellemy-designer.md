# Sellemy Designer Brief

Version: 8
> NON-CANONICAL LEARNING BRIEF. Current Visual canon and current task input always win. Keep this file compact; store only reusable Designer learnings that reduce retries or improve consistency.

## Purpose
記事テーマが文字なしでも伝わり、Sellemyらしい「わたしに、ちょうどいい。」「偶然の出会い」を感じるproduction eyecatchを、少ない探索・少ない再試行で生成する。

## Use
- 対象: `bu-codex-sellemy-designer` の記事アイキャッチ生成。
- Visual正本とcurrent task inputを優先し、このbriefは補助学習としてだけ使う。
- Planning / Writer知識、商品固有情報、slug、Task ID、日時、単発失敗ログ、正本の再掲は保持しない。

## Brand / visual heuristics
- 広告・EC販促ではなく、clean / calm / approachable / editorial。高級感や派手さより「自分の暮らしに合いそう」を優先する。
- 商品単体を押し出さず、使用場所・行為・前後状況を含む自然な生活文脈で見せる。
- 記事テーマを「主役となる物・行為」「使用場所」「使用前後の状況」に分解し、1つの場面として構成する。
- 商品を多数並べて説明しない。主役は1つの行為または場面に絞り、周辺物は文脈補助に留める。
- 比較記事でも優劣・順位・勝者を画像内で示さず、中立な編集視点を保つ。
- テキストで意味を補わず、物・手・収納場所・机上・洗面台などの関係で用途を読ませる。
- Visual Familyはテーマに合わせて選び、同一カテゴリでも同じ構図・背景色・部屋・自然光・カメラ角度を連続させない。
- 6商品の個別外観の正確な再現より、比較テーマを代表する生活シーンへの抽象化を優先する。

## Avoid
- grid / collage / contact sheet / 商品カード風montage
- 大きな記事タイトル、価格、ランキング数字、CTA、ボタン、長文コピー
- カテゴリ一般論だけの絵、カテゴリトップ画像の流用
- 完璧すぎるショールーム感、過剰なラグジュアリー感、極端な未来感
- 毎回同じ木目・正面構図・自然光・Lifestyle Sceneへの固定

## Learned
- 比較軸を見える形へ変換する。設置は底面と余白、操作は指と操作部、接続はコードや管の経路で示す。厚み・湾曲・毛丈は斜めから捉え、収納や槽は詰め込まず内側を見せる。透明容器は支持部と底面の間隔を同時に示しやすい。
- 主役の遮蔽物と撮影位置をセットで指定する。手は柄や本体側面に添え、刃・毛面・挿入口を隠さない。衣類は一部だけ掛ける。大型の台や脚物は全接地点まで余白付きで収める。長い柄は画面の対角線に沿わせ、人を脇に置くと全体と使用時の尺度を両立しやすい。
- 機構は部品数に加え、接続・向き・支持点を記述する。支点と両端、クランプと取付面、排水口と受け先などを連続した関係で示す。両手の役割を分け、生成後は貫通、接触位置、反復構造、コードの出入口を目視する。
- 似た道具との識別に必要な形を先に指定する。櫛状の刃、短い密な毛、大小のカードスロットなどを見せ、混同しやすい形は短く除外する。画面が識別の要なら必要な測定値と単位だけに絞る。
- 適合や使用条件が不明なら性能実演より準備動作を使う。対象物を空の槽の外に置く、閉じた洗剤を持って衣類の汚れを確認する、道具と未加工の食材を離して置くなど、効果や手順を断定せず用途を伝える。
- 周辺物は作業のつながりが分かるものを少数選ぶ。化粧品とクレンジング容器、カメラとカードリーダー、衣類とブラシなどの関係が、無地の主役でも記事固有性を補う。
- 構図はFamily名だけでなく高さ・距離・時間帯・占有率で指定し、実際の画像でFamilyを判定する。俯瞰や広角を指定しても斜めの接写になる場合がある。禁止した装飾や動作も残り得るため、プロンプトへの記載を検証の代わりにしない。
- image_genの戻り値全体は出力せず、保持した結果のoutput_hintから保存先を確認する。形式・寸法と画像内容は別々に検証する。

- 新しい学習は既存項目へ統合し、追記ログ化しない。
